# 🚁 JS-DJI AVATA 2
### Realistic FPV Drone for FiveM

**Goggles OSD · Motion controller · Real flight feel**

🎬 [**Watch the showcase**](https://youtu.be/q1cxw7PuSLE) · 🛒 [**Buy on Discord**](https://discord.gg/XEpk5MUJEh)

Put on the goggles, set the drone down, double-press **X** — and you're flying through Los Santos from the drone's camera.
Point the motion controller, squeeze the trigger, and it flies exactly where you look.
Built for RP, police, news crews and MilSim scouts.

## ✨ Features
- 🎒 **3 items to fly** — drone + goggles + motion controller *(optional stick controller for full Manual acro)*
- 🥽 **Goggles OSD** like the real one — REC, storage, satellites, signal bars, latency, battery, distance, height, speeds, home arrow
- 🎛️ **Flight modes** — Normal 8 m/s · Sport 16 m/s · Cine · Manual 27 m/s
- 🎯 **AR Cursor** — the drone goes where you point
- 🌀 **Easy ACRO** — flips, rolls and 180° drift · Turtle Mode
- 🔋 **Real battery** (~21 min) — low-battery Return-to-Home, forced landing
- 🛰️ **GNSS satellites**, wind and height limit
- 📶 **Signal loss** behind buildings and mountains — the picture breaks into blocks
- 📸 **Photo and video** — optional screenshots to a Discord webhook
- 💥 **Damage** — guards bounce, hard hits, gunfire, water
- ✈️ **AirSense** warning for manned aircraft
- 🚓 **Police `/remoteid`** — serial, height, speed and **the pilot's location**
- 🧍 **Gear on the character** — goggles and controller seen by everyone, with animations
- 🏷️ **Every device is unique** — serial number, battery cycles, frame and props condition

## 🎮 Controls
| Key | Action |
|---|---|
| `X` (double) | Motors on / off |
| `X` (hold) | Take off / land |
| `W` | Fly toward the cursor |
| `Mouse` | Aim the cursor |
| `G` | Flight mode · hold = Return to Home |
| `R` | Photo / video |
| `Wheel` | Gimbal tilt |
| `M` | Goggles menu |
| `Backspace` | Goggles on / off |
| `E` | Pick up the drone |

## 💬 Commands
| Command | What it does |
|---|---|
| `/remoteid` | Find drones and their pilots *(police)* |
| `/avatafit` | Fit the goggles / controller on your character |

## 📦 Requirements
- QBCore
- qb-inventory *(old and new)* or ox_inventory
- English + Hebrew included
